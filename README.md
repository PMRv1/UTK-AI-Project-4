# AI101-Assignment5
#This project uses the CrewAI framework to analyze baseball player statistics (Hitters.csv) and predict player value. It employs two specialized agents: a Baseball Data Analyst that extracts performance metrics and uncovers statistical trends, and a Sports Insight Synthesizer that turns those findings into actionable salary predictions and team strategies. During development, I overcame two main technical challenges. First, to avoid exceeding the model's token limits, I modified a custom reading tool to feed the agents a condensed statistical summary (using Pandas) instead of the full raw CSV. Second, to prevent execution errors when switching to a free-tier Hugging Face model, I changed the CrewAI process from a hierarchical structure to a sequential one, which successfully generated the final report.
